# Movie Watchlist App
A multi-page web application that searches the OMDb API for movies and allows users to save them to a local watchlist.

## How to run this locally
1. Clone this repository.
2. Get a free API key from [OMDb API](https://www.omdbapi.com/apikey.aspx).
3. Open `index.js` and `watchlist.js` and paste your key into the `api_key` variable at the top of both files.
4. Open `index.html` in your browser!
